DEVWORKBENCH V0.7 — versão candidata para testes
1. Mantenha a V0.6 intacta. Feche-a antes de copiar os dados.
2. Copie toda a pasta de dados da V0.6 para uma pasta DEV separada.
3. Extraia este ZIP em outra pasta de código e abra index.html no Chrome.
4. Selecione a CÓPIA dos dados. Compare links, URLs, descrições, tags, favoritos, notas, espaços, lembretes e foco.
5. Teste criação, edição, salvamento, fechamento e reabertura de cada módulo. Teste também prints e formatação.
6. Só após validação, faça backup atualizado e escolha a pasta de produção. Não use duas versões simultaneamente na mesma pasta.
7. Rollback: mantenha o código V0.6 e a cópia integral dos dados anterior à atualização. Dados novos precisam ser preservados separadamente antes de restaurar backup.
Arquivos JSON da V0.6 mantidos; tags.json é novo. Notas antigas são lidas como texto; notas novas possuem HTML sanitizado e exportação Markdown. Imagens são incorporadas como data URI, limite 5 MB por imagem. Não há upload automático. Utilize apenas dados e pastas autorizados pelo banco.
Editor usa recursos nativos do Chrome; conversão Markdown é parcial para elementos ricos. Visualizador CSV mantém dependências externas da V0.6. Daily, Wiki, Kanban e Assistente IA ainda não implementados.
Verificação realizada: sintaxe JS e referências estáticas. Teste de navegador e migração com dados reais ainda pendentes.
